# Code of Conduct

TakeOps wants a community where anyone can take part, whatever their experience, background or identity.

## Expected behavior

- Be respectful and assume good intent.
- Give and accept feedback about the work, not about the person.
- Help newcomers find their way.

## Unacceptable behavior

- Harassment, insults, or discriminatory jokes and language.
- Personal attacks, trolling or deliberate disruption.
- Publishing someone's private information without permission.
- Sexualized language or imagery.

## Scope and enforcement

This applies to all project spaces: issues, pull requests, discussions and any channel that represents the project.

Report problems privately to the maintainers, using the contact on the repository owner's GitHub profile. Reports are kept confidential. Maintainers may edit or remove contributions, and may warn, temporarily ban or permanently ban anyone whose behavior breaks this code.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
